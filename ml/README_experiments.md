# 实验跟踪

## 实验总结

### 基线模型
- 模型类型: RandomForestClassifier
- 准确率: 0.85
- F1分数: 0.84
- 超参数: n_estimators=50, max_depth=5

### 改进模型
- 模型类型: RandomForestClassifier
- 准确率: 0.92
- F1分数: 0.91
- 超参数: n_estimators=100, max_depth=10

## 生产就绪模型
我们选择**改进模型**作为生产模型，因为：
1. 准确率提高了7%
2. F1分数提高了7%
3. 在验证集上表现更稳定

## 优化指标
主要优化指标：**F1分数**
原因：F1分数综合考虑了精确率和召回率，对于不平衡数据集更合适。
